# Frontend component archive

This directory contains six reusable TSX components supplied separately: Checkbox, Collapsible, Command, Context Menu, Dropdown Menu, and Drawer.

They depend on React, Radix UI, cmdk, vaul, lucide-react, and the project's `@/lib/utils` and dialog component. They are not a complete editable frontend source tree. The running web UI is currently delivered as a compiled bundle under `promptforge-backend/public/`.

The original complete React/Vite source export (screens, contexts, app entry point, types, package manifest, and lockfile) was not included among the ten files uploaded in this conversation.
